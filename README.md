2. Загрузите все файлы из этой папки в репозиторий:
   ```bash
   git init
   git add .
   git commit -m "Launch Indigo Metaphysics Global Ecosystem"
   git branch -M main
   git remote add origin https://github.com/<ваш-аккаунт>/indigo-metaphysics-hub.git
   git push -u origin main
   ```

5. Через 1 минуту проект будет доступен по адресу:
   `https://<ваш-аккаунт>.github.io/indigo-metaphysics-hub/`
